How the pieces fit

Composable,
not finished.

“Composable harness” is a status, not a slogan. The loop is split so a local model, a scientific workflow, and a foreign agent can change without collapsing the safety boundary. Some seams are enforced by the linter. One important gate is deliberately not enforced yet.

  1. Operator The terminal, a headless clio-coder run, or an editor speaking ACP.
  2. Session A ledger, a working set, a routing overlay. Settings stay settings.
  3. Prompt Fragments compiled into one envelope, hashed, reused byte for byte.
  4. Tools One registry. Typed. Admitted. The same path for the main agent and a worker.
  5. Safety Policy, then autonomy. The prompt does not get a vote at execution time.
  6. Engine Pi, behind a boundary. Domains do not import the vendor SDK.
  7. Target Whatever model you pointed at. Localhost means the machine the worker is on.
  8. Dispatch A recipe, a node, a ceiling, a receipt. SSH is a transport, not a second product.

Five things people mix up

Skill
A procedure the agent can be told to follow. /skill. It is text and supporting files, not an executable tool.
Agent
A worker recipe: role, tools, budget, result contract. /run.
Fleet
A multi-step contract. Dependencies, gates, write boundaries. /fleet run.
Plugin
A domain bundle released together. Materio is the flagship: skills the peers can load, and Clio Coder-native agents, prompts, and a fleet that peers do not pretend to understand.
Extension
An executable capability. A declared Node or Python command, digest-checked, still passed through safety. Installing one does not register a skill, and browsing a skill does not register a tool.

That split is the intellectual bet. Vendor products collapse procedure, tool, and persona into one install. Clio Coder keeps them apart so a materials workflow can travel into Claude Code as skills, while the fleet that enforces a write boundary stays here, where the boundary is real.

What “experimental” means today

Enforced
Import boundaries. Workers do not pull the interactive app into a subprocess. Tools do not import the terminal. Pi stays in the engine. A project safety file is inert until its bytes are trusted. Receipts seal. Workers stay at default.
Shipped and early
The terminal is the product. The GUI is an opt-in alpha. Panes require Herdr. Some peer ACP recipes are pinned; some peers have only a headless path. Windows is best effort.
Designed, not enforced
The self-edit gate. High-authority edits to Clio Coder’s own harness were meant to require an evidence-linked change manifest. There is no signal yet that distinguishes “you asked Clio Coder to edit this repo” from “Clio Coder is editing itself.” A path glob would have blocked ordinary work. The gate waits. The note is in the repository on purpose.
Not claimed
An operating-system sandbox. Production GUI parity. That a local model outcodes a frontier model. That a peer’s shell is confined because Clio Coder asked nicely.

Add a capability without forking the loop

Write a skill if the missing thing is a procedure. Write an agent recipe if it is a bounded worker. Write a fleet if the steps and the gates are the product. Write a plugin if a domain should travel as one package. Write an extension only when the model must run a program you declared, with a schema, a timeout, and a digest.

Do not start by patching the chat loop. The architecture exists so you do not have to.

The harness is experimental because the seams are still being proven, not because the seams are a mood.

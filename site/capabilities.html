What is actually built

The loop,
opened.

This is the catalog. It is not a promise that every path has been exercised on your cluster. Released behavior is the git tag. The guides linked here are a snapshot shipped with this draft of the site.

Targets

A saved connection is a target. Chat, workers, and optional memory can each use a different one.

On your machine
Ollama, LM Studio, llama.cpp, vLLM, SGLang, Lemonade. Tool calling has to be real. Clio Coder will not pretend a model that cannot call tools can.
A gateway
LiteLLM, OpenAI-compatible and Anthropic-compatible endpoints. The lab’s server is a first-class place to work, not a fallback.
Cloud and subscriptions
OpenAI, Anthropic, Google, OpenRouter, Groq, Mistral, DeepSeek, Amazon Bedrock, Inception Mercury. ChatGPT through openai-codex. Claude through anthropic-max.
Institutional inference
Argonne ALCF Sophia and Metis through Globus OAuth. ALCF provider.
A warm prefix
The compiled prompt is reused byte for byte so a local server’s prefix cache stays warm. Clio Coder tells you when a turn went cold. Context engine.
Session routing
The model you pick for this turn does not have to rewrite settings.yaml. Overlays are session-local. Persisted settings stay put.

Safety is code

The prompt describes the rules. The registry enforces them whether or not the model followed the description.

Two levels
default runs workspace reads, edits, and recognized checks, and asks before unfamiliar commands, outward actions, and plan-scale dispatch. yolo clears those ordinary stops. It never outranks hard blocks, damage-control confirmations, or protected paths.
Who may set it
Only the operator, in user settings, /settings, configure, --autonomy, or an ACP session mode. Project settings cannot set autonomy. No tool, skill, worker, or model output can raise it. As of 0.5.6 the retired names auto-edit, full-auto, suggest, and read-only are refused.
Workers
Every dispatched worker and external peer runs at default, whatever the session level. Read-only is a dispatch restriction, not a third autonomy level.
Zero-access paths
.env, ~/.ssh/, *.pem, credentials, .git/config. Neither read nor written. A bash command that names one is blocked. Links are resolved before the judgment, so a symlink cannot walk out of scope.
Damage control
Recursive deletes, force pushes, git reset --hard, curl piped to a shell, cloud deletion commands, unbounded SQL deletes. Rules match each command a shell string would run, including chains, sh -c, and substitutions inside double quotes.
Project policy
A .clio-coder/safety.yaml takes effect only after the operator approves its exact bytes with clio-coder config trust safety.
Not an OS sandbox
Commands, hooks, and external agents run with your user permissions. Environment filtering narrows what a child inherits. It does not isolate the child. Vendor sandboxes do something Clio Coder does not. This page will not blur that.

Safety model guide

Evidence

A result you cannot reopen is a rumor.

Receipt
An immutable, cryptographically sealed record of a completed run: tools, tokens, validation grounding, outcome. Integrity version 20. The hash is the run’s, not a decoration on this website.
Trust algebra
Five axes: artifact integrity, validation grounding, independent review, context provenance, completion evidence. No axis promotes another. absent, unknown, and not_applicable are states. The compact line is fixed: who claims the result, what was observed, what was independently checked, what is still unknown.
Finish contract
A turn that changed files looks for validation evidence or a limitation receipt. With neither, the model is told to report the change as unverified.
Host checks
Checks named in a dispatch run on the host after the worker finishes. The worker’s report is a claim until then.
Trace
A SQLite mirror beside the ledger. Rebuildable. clio-coder trace can list runs, phases, and processes without pretending the trace is the science.
Memory
Approved, evidence-linked records. The rules-only tier is on by default and makes no model call. An LLM memory tier is opt-in, on its own target, and does not change the action agent’s tools. Proactive memory.

Context that can come back

Summaries that throw the original away are how long sessions go quietly wrong.

Working set
The part of the ledger the model sees next. Eviction removes a body from that view. It does not delete the ledger entry, the transcript, /resume, /fork, or the HTML export.
Markers
The stub that replaces an evicted body is byte-stable. No timestamp, no counter. A marker that drifted would cold-start the prefix cache on a turn that evicted nothing new.
Recall
/context recall or the context tool re-admits a body by ref. The marker stays, so the cache prefix is untouched.
Handbook
CLIO-CODER.md, human-owned, versioned with the project. clio-coder context init drafts it. Runtime state stays under .clio-coder/.
Codewiki
A Tree-sitter index for large trees. Parsing does not run on the interactive input loop. A workspace that has never been indexed is not scanned in the background at session start.
Tree, fork, export
/tree, /fork, /resume. /export writes HTML. /export notes.md writes Markdown. Compaction has a recovery path if a handoff is interrupted.

Workers and fleets

A worker is a subprocess with a recipe, a ceiling, and a receipt. Distance does not change the protocol.

Capability class
read-only, verification, artifact-write, workspace-edit. The class is the maximum mutation boundary, not a suggestion in the prompt.
Shipped agents
architect, coder, debugger, documenter, git-master, tester, verifier, wiki-writer. Shadow and internal: scout, researcher, world-knowledge, provenance, oracle, context-bootstrap. Scout may cite only a line it actually read.
Contracts
A recipe can require a result shape. A small model that gathered the right evidence gets two repair rounds with the validator’s own reason, then the run fails. It is not failed in silence for a shape mistake nobody named.
Topologies
Parallel, sequential, pipeline, review, compete, council, fleet. Shipped contracts: build-test, build-review, sdlc. Compete and council are gates, not vibes.
SSH
The same NDJSON protocol, tunneled. localhost in a worker target means that node’s inference server. Remote nodes are expected to see the project at the same absolute path. Doctor checks the parity.
Worktrees and leases
A task can run in its own git worktree. One checkout-writer lease per checkout. A second process is refused rather than interleaved.
Steering
Enter steers a live turn. Ctrl+Q queues. Escape interrupts. Alt+W is the fleet board. Origin glyphs: ◇ you asked, ◆ the model asked.

The code science runs on

Ordinary engineering works. The extra surface is why this exists.

verify
Runs the checks the repository already declares: pytest, unittest, Cargo, Go, CMake presets, Make, just, CI scripts. Compares numerical results. Holds performance budgets.
Slurm
Through the clio-kit MCP server: submit, poll, cancel, fetch output. The skill stamps the scheduler result. It does not invent a second scheduler. Slurm guide.
MCP gateway
One gateway in front of configured servers. Project servers need an explicit trust decision. toolkit.iowarp.ai is the scientific kit beside this harness.
Materio
A materials-research plugin: literature from a supplied corpus, a virtual lab, an assumption-driven task plan, inspected artifacts, a reviewed handoff. Domain knowledge, not a hidden host capability. Library.
Research skills
arXiv literature cards, experiment protocols, scientific debugging, scientific modernization, Slurm jobs. Procedures with a boundary, not a chatbot persona.

Composition

The other agent can be a worker. It does not have to be the landlord.

Peers
Claude Code, Codex, OpenCode, Antigravity CLI, Pi. ACP where a recipe exists, headless CLI, or a Herdr pane. A pane is a handoff and has no managed receipt. Selection is explicit.
Clio Coder as a peer
clio-coder acp serves editors and hosts. Session list, resume, modes, and configuration are advertised. The custom methods live under the _clio-coder/ prefix ACP reserves.
Library, both ways
This repository is a Claude Code marketplace. Codex can link the same skill trees. Nothing is converted. Packages that a peer would misread as native agents are left out of that projection, and the pin script says why.
Extensions
Command tools in Node or Python, declared, digest-checked, still subject to the safety policy. An extension is not a sandbox and not a plugin. Plugins are the domain bundles. Harness.
Panes
Optional Herdr panes beside the session, and a Yazi files pane. Off unless you turn them on. Clio Coder does not edit Herdr’s config for you.

Limits, on the same page

A capability page that omits these is an advertisement.

Experimental 0.5.6 Terminal-first GUI alpha Not an OS sandbox Windows: best effort Self-edit gate deferred

The graphical application is an opt-in preview for docs, sessions, and telemetry. It claims no parity with the terminal. Commands run with your user permissions, not an operating-system sandbox. The self-edit gate — evidence required before Clio Coder edits its own high-authority harness paths — is designed and not enforced. A naive path glob would have blocked ordinary edits you asked for. That was refused. See Vision.

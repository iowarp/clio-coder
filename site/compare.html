Delegate to an
installed coding agent.

Authenticate the peer through its own CLI first. Clio detects available connectors and records their capabilities.

Supported peers
Claude Code, Codex, OpenCode, Pi, and Antigravity CLI. Connector support varies between ACP, headless CLI, and companion-pane modes.
Managed task
Give the peer a focused assignment and, where supported, an isolated Git worktree. Inspect its reported result and the host checks.
Companion pane
Open an interactive peer beside your session through Herdr. This is a handoff rather than a managed worker run.
Read-only limits
Connectors use the peer’s own restrictions. Codex uses a read-only sandbox, Claude Code uses plan mode, Pi uses read tools, and Antigravity uses plan mode with sandbox. OpenCode refuses read-only headless delegation before launch.

Connect to editors
and other hosts.

ACP means Agent Client Protocol: a standard connection between a coding-agent runtime and its client. 

clio-coder acp

Clio’s ACP server advertises session list, resume, modes, and configuration. Clio-specific methods use the protocol’s reserved _clio-coder/ prefix.

The GUI also uses ACP to communicate with the runtime. It is an alpha with its own evolving feature coverage.

Bring scientific
infrastructure into a session.

MCP means Model Context Protocol: a way to expose external tools through configured servers.

One gateway
Clio routes configured MCP servers through one gateway and applies project trust decisions before using project-defined servers.
Scientific toolkit
The adjacent clio-kit project provides scientific MCP servers, including Slurm workflows.
Scheduler workflow
With the kit installed and trusted, submit a job, poll its state, and fetch its output. A scheduler result is separate from scientific validation.

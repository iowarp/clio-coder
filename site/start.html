Installation

Meet your new
terminal companion.

You need Node.js 22.19 or newer and a model with tool calling. Linux and macOS are the primary platforms; Windows support is best effort.

InstallConnect a modelFirst sessionGUI alphaTroubleshooting
01

Install the agent

One package. Your machine.

Install the published package with npm:

npm install -g @iowarp/clio-coder
Other ways to install
pnpm
pnpm add -g @iowarp/clio-coder
Try without installing
npx --yes @iowarp/clio-coder@latest
Skip the optional Claude SDK
npm install -g @iowarp/clio-coder --omit=optional. Chat and native workers do not require it.
Build from source
Clone the release tag v0.5.6 and run pnpm run install:local. The launcher installs in ~/.local/bin.
Installation and lifecycle guide →
02

Choose your model

Local, lab, or cloud.

Open the configuration launcher from your project directory.

cd /path/to/your/project
clio-coder configure

Choose Quick Connect. Enter your server’s endpoint, credentials if required, and a model that supports tool calling.

Ollamahttp://localhost:11434
LM Studiohttp://localhost:1234

For cloud APIs, subscription sign-in, and institutional inference, open Settings → Connections. Chat and workers can use different connections.

03

Start small

Get to know your repository.

clio-coder

Start with a concrete request that helps you check the agent’s understanding: 

Explain how this repository builds and runs its tests.
Find the main entry points and suggest one useful verification task.
Do not change files yet.

The terminal shows tool calls and permission decisions as the agent works. Use /help for commands, /model to switch models, and /context to inspect the current context.

Steer a live turn
Press Enter to steer, Ctrl+Q to queue a follow-up, and Escape to interrupt.
Review a permission request
Deny skips that call. Stop ends the turn.

A browser interface,
when you want one.

An opt-in GUI alpha is included with the package. It currently covers a subset of terminal workflows.

Open a foreground session

clio-coder gui --open

Keep a local service running on Linux

clio-coder gui background install --open

The GUI uses React/Vite in the browser, a Node/Hono HTTP and server-sent events service, and ACP over stdio to the Clio runtime. Check clio-coder gui --help for your installed version’s options.

The local launch link contains a private token. Keep that link private.

Need a hand?

Use the diagnostic tools before changing your configuration.

clio-coder --version
clio-coder doctor
clio-coder paths

Plain doctor is read-only. doctor --fix performs the repairs it reports. The installed documentation is available with clio-coder docs.

Upgrading from an older autonomy configuration

Version 0.5.6 accepts only default and yolo for safety.autonomy. Replace retired values in your user settings.yaml: auto-edit, suggest, and read-only become default; full-auto becomes yolo. Project settings cannot set autonomy. Use clio-coder paths to locate your configuration.

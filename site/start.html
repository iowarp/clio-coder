You need Node.js 22.19 or newer and a model that can call tools. Linux and macOS are the primary platforms. Windows is best effort. Nothing here starts a graphical app unless you ask.

npm install -g @iowarp/clio-coder --omit=optional. Chat and native workers do not need it.
From source
Clone tag v0.5.6, then pnpm run install:local. The launcher lands in ~/.local/bin.

Then this

cd /path/to/your/project
clio-coder configure
clio-coder

In Quick Connect, give an endpoint such as http://localhost:11434 for Ollama or http://localhost:1234 for LM Studio, a key if the server wants one, and a model that supports tool calling. Subscriptions and other providers are under Settings → Connections.

Upgrading to 0.5.6. safety.autonomy accepts only default and yolo. Older values are refused and Clio Coder will not start while your user settings.yaml holds one. auto-edit, suggest, and read-only become default. full-auto becomes yolo. Edit the file by hand. clio-coder paths shows where it is. Project settings can no longer set autonomy.

Open the graphical application

An opt-in alpha, included with the package.

The GUI uses a local browser interface and the same Clio runtime. For a foreground session, run:

clio-coder gui --open

On Linux, install the persistent user service to keep a stable local origin and reopen the application without holding a terminal open:

clio-coder gui background install --open

Use clio-coder gui --help for the options supported by your installed version. The GUI currently covers a subset of terminal workflows. Its local launch link contains a private token; keep that link private.

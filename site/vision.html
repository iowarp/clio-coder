About Clio Coder

Open software.
Inspectable scientific work.

Clio Coder is part of IOWarp’s CLIO ecosystem. It brings model choice, explicit tool policy, and recorded checks to the software research depends on.

Built for the people
who maintain research code.

From simulation kernels and numerical libraries to data pipelines and mixed-language builds.

The runtime is open source under Apache-2.0, so teams can inspect how tools are admitted, how workers are bounded, and how evidence is recorded. Clio builds on the Pi agent framework.

The name Clio refers to the muse of history. In IOWarp, CLIO also names the Context Layer for Input/Output. Clio Coder is the coding-agent product; clio-kit and other CLIO projects retain their own identities.

Where the
product stands.

Experimental v0.5.6, with active development on the version branch.

Available in the terminal
Local and cloud targets, runtime safety policy, workers and SSH fleets, run records, context tools, pinned library resources, ACP, and installed documentation.
Alpha and evolving
The optional graphical application, Herdr and Yazi companion panes, and some peer ACP connector recipes.
Deferred
The high-authority self-edit gate and container or cloud worker transports.
Product limits
No operating-system sandbox or GUI parity claim. Linux and macOS are primary; Windows support is best effort. Model output and passing checks do not establish scientific correctness.

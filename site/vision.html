CLIO · Context Layer for Input/Output

A muse,
and a ledger.

Clio is the muse of history. The architecture is a context layer for input and output. The product on this site is Clio Coder, not clio-agent, not clio-core, and not clio-kit. Those names stay distinct so a scientist can tell which instrument they are holding.

The ecosystem

iowarp.aiThe project. Context for scientific work, not a chat brand. toolkit.iowarp.aiLive. MCP servers for Slurm, HDF5, ADIOS, Spack, and the rest of the kit.
coder.iowarp.aiRecommended home for this site. The product name is Clio Coder. The host should say so.
clio.iowarp.aiOptional alias. Fine as a redirect. Risky as the only name, because bare Clio already means other things in this ecosystem.
agent.iowarp.aiNot this product, and not claimed as live from this draft. A future agent surface should not borrow Coder’s receipts.
grc.iit.eduGnosis Research Center, Illinois Tech, with the University of Utah.

Status, without a roadmap costume

Shipped

  • Terminal agent
  • Targets, including local and ALCF
  • Coded safety, two levels
  • Sealed receipts
  • Workers and SSH fleets
  • Library with pins
  • ACP server and peer connectors
  • Docs inside the package

Alpha

  • Graphical application
  • Herdr panes and Yazi
  • Some peer ACP recipes
  • This website

Deferred

  • Self-edit gate
  • Container or cloud worker transport

Not claimed

  • OS sandbox
  • GUI parity
  • Windows as a primary platform
  • Better code than a frontier model

Why it is public

The IOWarp CLIO architecture is supported by the National Science Foundation under Award 2411318, 2024–2029. Principal Investigator Xian-He Sun. Co-Principal Investigators Anthony Kougkas, Jake Hochhalter, and Vivek Srikumar. The harness is Apache-2.0 because a scientific instrument that you cannot read is a vendor relationship.

Contributions target the current version branch. main advances when a release ships. A difficult build, a bad connection, or a workflow that needs too much babysitting is a useful bug report. Include versions, steps, and clio-coder doctor output, with credentials removed.

The work has to remain inspectable after the grant, the model, and the vendor have all changed.

Cite it. Clio Coder. Gnosis Research Center, Illinois Institute of Technology, with the University of Utah. github.com/iowarp/clio-coder. Apache-2.0. NSF Award 2411318.

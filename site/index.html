A different bet

Your research code may need a local model, a university gateway, a cloud API, or a specialist coding agent. Clio Coder puts those choices behind one inspectable runtime, with consistent policy, bounded assignments, and durable evidence.

Clio Coder was built for the people who maintain the code science runs on. Simulation kernels. Numerical libraries. Data pipelines. Mixed-language builds. It is just as useful on an ordinary repository. Point it at Ollama, a lab gateway, Argonne ALCF, or a cloud API, and the receipt looks the same.

It will not out-code a frontier model by slogan. A small local model inside an honest harness is still a small local model. The claim is the harness: strong enough that your own hardware can do real work, and honest enough that you can check what happened.

The model is a choice.
The evidence is yours.

Standing on Pi. The engine boundary is the Pi agent framework. Clio Coder owns policy, evidence, fleets, and the scientific surface. The runtime stays swappable.

Before your first session

What runs, where it runs, and what stays under your control.

What is Clio Coder?

Clio Coder is an Apache-2.0 AI coding agent and runtime for scientific software. Its terminal interface brings together repository tools, model routing, bounded delegation, reusable skills, and inspectable run evidence. Start with the installation guide or explore the capabilities.

Can I use a model running in my lab?

Yes. Connect local and remote model servers such as Ollama, LM Studio, and llama.cpp, or an OpenAI-compatible gateway. You can route chat and workers separately. A model must support the tool use your workflow requires. The configuration guide explains the options.

Do I need a hosted Clio account?

No. The harness runs on your machine with your configuration and model access. Cloud providers may require their own credentials and charge for inference. You choose the endpoint; Clio Coder does not require a central hosted account.

What does the evidence actually prove?

A run receipt records what was observed and checked, with separate trust states and provenance. A successful command does not establish scientific correctness. Keep your reference tests and data in the workflow, and use the evidence guide to understand the record.

Is there a graphical application?

The package includes an opt-in GUI alpha. It uses a browser interface backed by the Clio runtime. Terminal and GUI feature coverage currently differ; the terminal remains the primary interface. See GUI setup for launch and background installation options.

How can I contribute?

Read the source on GitHub, report a reproducible issue, or build a reusable skill. The library authoring guide shows how to share a procedure that others can inspect and run.

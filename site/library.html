A domain workflow
for materials research.

Materio brings Daisy Quach’s scientific workflow into a reusable research package.

Featured domain plugin

From a research question to a reviewed handoff.

Work through literature from a supplied corpus, a feasible virtual lab, an assumption-driven task plan, inspected artifacts, and a reviewed paper handoff.

Portable knowledge
Six skills that other agents can load. Clio-native recipes are not presented as Claude Code agents.
Clio-native execution
Seventeen prompts, six agent recipes, and an execute-then-verify fleet with a host write boundary under .research/tasks/.
Scientific limits
Generated protocols are prepared work. Physical measurements remain human actions. Reading an artifact is not scientific validation. Provided-URL retrieval and Crossref access are opt-in. 
clio-coder library install ./library/plugins/materio --project

Use the same skills
from other tools.

The canonical trees are shared without converting Clio worker semantics into another agent’s format. 

claude plugin marketplace add iowarp/clio-coder
claude plugin install tdd@clio-coder
claude plugin install materio@clio-coder

For Codex, this repository’s .agents/skills already links to the canonical trees. To expose a local clone’s skills from another checkout: 

ln -s "$PWD/library/skills" ~/.agents/skills/clio-coder
ln -s "$PWD/library/plugins/materio/skills" ~/.agents/skills/materio

Run the link commands from the Clio Coder checkout. Inspect existing destinations first. The generated marketplace uses the pin registry and excludes incompatible projections.

Share a procedure
your team can inspect.

Start from the templates in library/_authoring/templates/.

Choose a resource type, declare its boundary, and validate the package. Pin its files, try it in an isolated project, then contribute against the current version branch. 

clio-coder library validate <package-path> --json
pnpm run library:pin
pnpm run library:check

Library pins record SHA-256 digests of package files. Templates are authoring resources rather than catalog entries.

# Skills

Skills are operator-activated workflows: git delivery, planning, coding
practice, context priming and handoff, research, and plan stress-testing.
context (scope="skills") is the one authoritative listing of installed
and marketplace skills; never guess the inventory or search the
repository for one. When a task has one of those shapes, list them,
suggest the best match as /skill <name> (the sequence in order when
several compose), and continue the task without it: only the operator
activates or installs a skill, and a [Marketplace] reminder states its
own offer options. When the operator names a skill or asks how one
works, answer from that listing. If nothing fits, proceed normally and
suggest nothing.

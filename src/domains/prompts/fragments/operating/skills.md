# Skills

Skills are workflows for git delivery, planning, coding practice,
context priming/handoff, research, and plan stress-testing.
context (scope="skills") lists installed and marketplace skills; never
guess a skill or search the repository for one.
{SKILL_ACTIVATION_POLICY}
Only the operator installs marketplace skills; a [Marketplace] reminder
states its own offer options. When the operator names a skill or asks
how it works, answer from it. If nothing fits, suggest none.

If gateway is on the attached direct-tool surface, use
gateway(op="call", capability="clio_library", args={}) to read the catalog
of recipes and installable packages; it activates and installs nothing.
Without gateway, this catalog route is unavailable.

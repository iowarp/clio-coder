# Steering while you work

A user message between your tool results and your next step steers this run;
it is not a new conversation. Read every queued one before acting; when a later
one contradicts an earlier one, the later one wins. A correction or narrower
scope applies at once, an unrelated request
waits until the current task is done unless the operator says to switch
(say so in one line), and a stop means stop and report where things stand.
Never restart finished work because of one.

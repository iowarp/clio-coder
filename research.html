Clio Coder / Research

Open questions, and how to work on them.

Each page states a question, what is known and measured so far, and a first experiment you can run with Clio Coder, labelled “proposed, not yet run” until someone has. The team, students, and outside researchers are welcome: open a GitHub issue to join, and read the contributor guide. What has shipped is in Docs and Tutorials.

Decision models / 12 min

Can a small decision model improve an agent's work?

System One's open questions: evaluating on trajectories, forming better questions, and bringing or one day training a model, with what is measured so far and a first experiment.

Open question. System One is off by default.

Reproducible agent science / 10 min

Can an agent run be a scientific record?

What a sealed run record proves and what it cannot, how far repeated runs differ, and a first experiment to measure that spread with Clio Coder.

Open question. The records have shipped; no study exists yet.

Whether lessons change what an agent does, whether self-approval is safe, and a first experiment on one repeated mistake.

What does an agent lose when its context is reduced?

Fidelity of summaries, the cost of reduction, and search by meaning, with a first experiment that counts how many planted facts survive.

# Code of Conduct

Clio Coder is built in the open by researchers, students, research software
engineers and people who run models on their own machines. Everyone is welcome
to ask a question, report a problem or propose a change, whatever their
experience with the code.

Expected behavior:

- Be direct, factual and constructive.
- Critique code and decisions, not people.
- Assume a question is asked in good faith, and answer it that way.
- Keep issues and pull requests on topic.
- Disclose conflicts of interest when they affect a proposal.
- Respect maintainer decisions on scope, roadmap and release timing.

Unacceptable behavior:

- Harassment, threats or personal attacks.
- Posting secrets, private logs or credentials.
- Spam, low-effort automation or generated noise.
- Bypassing review, CI, branch protection or the security policy.

The maintainer may edit, lock, close, hide or ban activity that violates these
rules.

## Reporting and enforcement

Report conduct concerns privately to `a.kougkas@gmail.com`. Include enough
context to assess the incident, and leave out unrelated private material.
Security vulnerabilities use the separate process in [SECURITY.md](SECURITY.md).

These expectations apply to the project's issues, pull requests, discussions
and other project-managed collaboration spaces. Maintainers explain moderation
decisions where appropriate and handle reports respectfully.

Overview Summary

Clio connects directly to Argonne National Laboratory's ALCF inference gateways Sophia and Metis. This connection uses an OpenAI-compatible API target authenticated via Globus OAuth client PKCE flows.

Select Gateway Target

Choose an ALCF supercomputing cluster to generate configure commands.

Generated Configuration Commands

Run these commands inside your Clio Coder session to login and save the target profile:

clio-coder auth login alcf
clio-coder configure ...
clio-coder targets use alcf-sophia

Globus OAuth Paste-Code Login

Clio's interactive SSH-friendly OAuth PKCE loop sequence:

1

Launch Authentication Command

Operator executes: clio-coder auth login alcf

2

Authorize via Browser

Clio prints a secure Globus URL. Click to approve and log in through ANL portal.

3

Paste Authorization Code

Globus displays a code. Paste it back into the Clio prompt:

4

Token Resolved & Saved

Clio exchanges code for OAuth token, verifies it, and stores the encrypted credential locally.

Configure Details

Sophia currently maps to /resource_server/sophia/vllm/v1 and Metis maps to /resource_server/metis/api/v1. Wire model IDs must be exact; Metis uses bare names while Sophia uses openai/ prefixes.

Implementation files

  • src/engine/alcf-oauth.ts: PKCE pasting flows
  • src/domains/providers/runtimes/cloud/alcf.ts: Sophia/Metis discovery models

Chat Templates Exception

ALCF gateways reject custom client-side chat_template_kwargs. Clio automatically handles this by flagging target profiles with clio.chatTemplateKwargsUnsupported, which strips this field from request bodies before transmitting.

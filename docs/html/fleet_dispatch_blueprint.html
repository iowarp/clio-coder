Fleet Dispatch v0.2.9 Overview

Clio's Fleet Dispatch orchestrates parallel worker agents across local processes and remote HPC nodes via SSH transport. In v0.2.9, dispatch includes Scout-first exploration routing, integrity-sealed receipt verification, worker capability compilation, batch budget reservations, and circuit-breaker failover.

Scout-First Bounded Reconnaissance & Synthesis Budget

Broad search and exploratory tasks are automatically routed to Scout workers with bounded synthesis context and budget reservation.

orchestrator$ clio dispatch --query "explore repository architecture and dependencies"
[dispatch] evaluating task profile: broad reconnaissance query detected.
[dispatch] applying Scout-first split recommendation (synthesis budget: 4,000 tokens).
[scout-1] launched on node-login-01 (SSH). Collecting evidence receipts...
[scout-1] evidence collected: 14 target files identified. Digest hash: sha256-a9f81b...
[orchestrator] bounded synthesis turn executing with verified evidence receipts.

Typed Failure Taxonomy & Circuit Breaker Attribution

When remote worker dispatches fail, typed taxonomy categorizes errors and triggers assignment-aware failover without corrupting session state.

Failure Class Trigger Cause Failover Action Circuit Breaker Status
timeout Worker stdout idle > 300s Reassign to healthy node Half-Open (1 penalty)
tool_failure Incompatible tool invocation Re-compile worker profile Closed (Normal)
exit_status SSH connection dropped (code 255) Drain node & failover Open (Tripped)

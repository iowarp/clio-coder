Overview Summary

Clio Coder compiles one deterministic system prompt per session keyed by target|model|autonomy|sessionId|workingContextPaths, manages shell-style template expansion ($1..$9, $@, $ARGUMENTS), supports directory handbook overrides, and bounds tool executions across seven formal planes.

Layered Prompt Architecture

Constitutional & Operating Fragments

  • identity.clio & operating.contract: Universal rules rendered unconditionally.
  • safety.<level>: Single effective autonomy matrix in action-class terms (read, write, command, system_modify, git_destructive).
  • operating.delegation: Rendered only when dispatch is in the session tool surface.
  • operating.skills: Rendered only when context(scope="skills") is available.

Prompt Templates & Directory Overrides

Template Expansion

Supports shell-style parsing with quotes, $1..$9 positional parameters, $@, and $ARGUMENTS joined strings. Collisions with slash commands fail closed.

Directory Overrides

CLIO-CODER.override.md creates an isolated subtree handbook boundary, overriding parent handbook guidance for descendants while leaving siblings unaffected.

Core Architectural Concepts

Filter terms across the 40 definitions:

Assignment DurableAssignmentRecord (src/domains/dispatch/assignment-store.ts)
The logical unit of work dispatched to the fleet. An assignment encapsulates task text, briefing, authority boundaries, and retry history across one or more concrete run attempts.
Run RunEnvelope (src/domains/dispatch/types.ts)
A concrete execution attempt of an assignment. Every run possesses a unique UUIDv7 identifier, an isolated event stream, a designated execution node, and a final cryptographically sealed receipt.
Receipt RunReceipt (src/domains/dispatch/types.ts, v16)
An immutable, cryptographically sealed record of a completed run containing full execution facts, tool telemetry, token accounting, validation grounding, and outcome codes.
Attempt RunLineage.attempt (src/domains/dispatch/types.ts)
A 0-based sequential retry index of a logical assignment. Retries after infrastructure errors increment this index while preserving previous run records and receipts.
Batch DetachedBatchRecord (src/domains/dispatch/batch-store.ts)
A durable collection of detached assignments created and tracked together under a single batch ID in batches.json.
Plan ExecutionPlan (src/domains/dispatch/execution-plan.ts)
A multi-step directed acyclic graph (DAG) defining steps, dependencies, code validations, and budget ceilings approved by the operator before dispatch.
Topology ExecutionPlanTopology / DispatchPlanTopology
Multi-agent structural orchestration pattern governing workflow execution: parallel, sequential, pipeline, review, compete, and fleet.
Route RouteCandidate (src/domains/dispatch/route-decision.ts)
An exact execution tuple composed of { agent, target, model, node } evaluated by the active route planner for capability fit and cost readiness.

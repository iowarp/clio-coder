Overview Summary

Clio Coder treats the conversation as a durable directed tree graph written to an append-only JSONL ledger (current.jsonl) with atomic metadata (meta.json) and branch definitions (tree.json). Version 0.3.2 provides complete turn settlement before session switches, self-contained HTML exports, directory-scoped handbook overrides, and process-local prompt history.

On-Disk Session Directory Structure

<stateDir>/sessions/<cwdHash>/<sessionId>/
  meta.json        # ClioSessionMeta JSON document (atomic write, CURRENT_SESSION_FORMAT_VERSION = 3)
  current.jsonl    # Append-only structured session event ledger (O_APPEND, single write(2) calls)
  tree.json        # SessionTreeNode[] conversation tree graph for non-destructive branching

Core Lifecycle Guarantees

Streaming Turn Settlement (#114)

When switching sessions via /new, /resume, /tree, or /fork while a model turn is streaming, settleChatBeforeSessionSwitch cancels the stream and awaits completion, ensuring ledger writes commit before the writer is replaced.

Self-Contained HTML Export

/export writes a standalone HTML document by default (or Markdown when targeting .md). The export is capped at 2 MiB, converts ANSI styles to inline theme colors, and renders semantic tool rows for the active branch only.

Directory Handbooks & Prompt History

Directory Overrides

CLIO-CODER.override.md replaces inherited instructions for its directory subtree while isolating siblings. Malformed files fail closed.

Prompt History (Ctrl+P / Ctrl+N)

Accepted prompts, slash commands, and steering inputs are preserved in process-local history. Rejected inputs stay in the composer without polluting history.

Turn Settlement Safety (#114)

When switching sessions via /new, /resume, /tree, or /fork during an active stream:

settleChatBeforeSessionSwitch cancels the in-flight stream and awaits completion. The partial turn and completed tool executions seal cleanly into the original session ledger before the session writer is replaced, preventing orphaned root entries or lost answers.

On-Disk Session Directory Structure

<stateDir>/sessions/<cwdHash>/<sessionId>/
  meta.json        # ClioSessionMeta JSON document (atomic write)
  current.jsonl    # Append-only structured session event ledger (v3)
  tree.json        # SessionTreeNode[] conversation tree graph

Session Metadata Schema (`meta.json`)

Field Type Description
id string UUIDv7 session identifier generated at initialization.
cwd string Absolute workspace root directory at session creation.
cwdHash string First 16 hexadecimal characters of SHA-256 of canonical resolve(cwd).
createdAt / endedAt string / string | null ISO-8601 UTC timestamps for session start and completion.
model / target string | null Active model selector and target identifier.
clioVersion string Clio Coder release version (0.3.7).
sessionFormatVersion number CURRENT_SESSION_FORMAT_VERSION = 3 (src/engine/session.ts:66).
pinnedLeafTurnId string | null Active leaf turn pinned via /tree, cleared on next append.

Append-Only Ledger Taxonomy (`current.jsonl`)

Every line in current.jsonl is a complete JSON document written via O_APPEND file descriptors:

  • Header Frame (Line 1): {"type":"session","version":3,"id":"...","timestamp":"...","cwd":"..."}
  • Message Entry (kind: "message"): User inputs, assistant thoughts/prose, and tool calls/results.
  • Label Entry (kind: "label"): User-defined bookmark anchored to a specific targetTurnId.
  • Session Info Entry (kind: "sessionInfo"): Model switches, target migrations, and thinking dial updates.
  • Compaction Summary (kind: "compactionSummary"): Progressive summary preserving historical context up to firstKeptTurnId.

Protected-Artifact Write-Ahead Journal

Location: <stateDir>/protected-artifact-pending/<sessionKey>/<recordId>.json

Staging & Commit Lifecycle

  1. Stage: Mutating tool results stage artifact registration to the pending directory before returning.
  2. Commit: When the turn finishes and appends to current.jsonl, the staged file is unlinked.

Reconciliation on Startup

During /resume, reconcilePendingProtectedArtifacts checks for leftover journal entries and restores protected artifact locks before user interaction begins.

Session Resumption & CWD Fallback

When resuming via /resume or CLIO_CODER_RESUME_SESSION_ID, resolveSessionCwd validates the recorded workspace path:

Condition Failure Reason Remediation Behavior
Directory exists and is readable null (valid) Resumes session immediately without prompts.
meta.cwd is empty or missing no-cwd Opens CWD-fallback dialog to select current directory.
Directory path no longer exists missing Opens CWD-fallback dialog with path suggestion.
Path points to a non-directory file not-a-directory Prompts operator for valid directory path.

Transcript Export Contract (`/export`)

Self-Contained HTML (Default)

  • Path: .clio-coder/exports/<sessionId>-<local-date>.html
  • Carries converted ANSI styling with full Clio theme colors.
  • Semantic tool rows with expandable parameters and output.
  • Self-contained: 0 external scripts, stylesheets, or images.
  • Bounded: Capped at 2 MiB; truncates cleanly at whole row.

Plain Markdown Export

  • Requested by specifying an explicit .md file extension.
  • Heading with UTC instant, metadata, and fenced text.
  • Terminal escape codes and controls stripped cleanly.
  • Follows active leaf path; omits pruned sibling turns.

Directory Handbooks & Prompt History

Handbook Subtree Overrides

CLIO-CODER.override.md replaces inherited instructions for its directory subtree:

  • Creates explicit subtree boundaries without affecting sibling directories.
  • Subdirectories can add narrower rules with additional override files.
  • Context resets never delete override files.

Prompt Navigation History

Process-local navigation via Ctrl+P / Ctrl+N:

  • Preserves accepted chat, slash, steering, and follow-up inputs.
  • Consecutive duplicate prompts are collapsed.
  • Malformed inputs remain in editor without polluting history.
  • Forward navigation restores the unfinished draft.

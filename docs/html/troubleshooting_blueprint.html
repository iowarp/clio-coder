Error Catalog & Remediation

clio-coder run cannot confirm permission requests; rerun interactively to approve this action.
A tool call required permission during headless execution. Run interactively in the TUI (clio), adjust .clio-coder/safety.yaml, or run with --autonomy full-auto if safe.
<arg> is a global option and must come before the subcommand...
Global flags like --api-key or --no-context-files must precede the subcommand (e.g. clio-coder --api-key <k> run ...). Directory overrides use environment variables (CLIO_CODER_*_DIR).
LM Studio duplicate model load / peer projection
Clio automatically resolves model IDs to resident host instances to prevent duplicate VRAM allocations. Verify loaded instances with clio-coder targets --probe.
llama.cpp 400 model is already running
Sleeping models are treated as resident by the reconciler. Verify router slots and catalog models before initiating eviction.
OAuth token exchange cancelled
An in-flight login was aborted. Lock waiters cancel immediately without corrupting credentials. Run clio-coder auth login <target> to restart cleanly.

Diagnostic Commands

# Full system health verification and auto-repair
clio-coder doctor --fix

# Probe all configured targets for connectivity and loaded context
clio-coder targets --probe

# Inspect live event streams for a specific worker run
clio-coder trace tail <runId>

# Check cryptographic evidence and execution receipts
clio-coder evidence inspect <runId>

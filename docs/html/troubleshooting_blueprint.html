Error Catalog & Remediation Matrix

Type any keyword or message fragment to filter actionable remedies:

clio-coder run cannot confirm permission requests; rerun interactively to approve this action.
Cause: A mutating tool required manual permission approval during headless execution.
Remedy: Rerun interactively in the TUI (clio) for one-shot approval, adjust workspace policy in .clio-coder/safety.yaml, or pass --autonomy full-auto if safe.
<arg> is a global option and must come before the subcommand: clio-coder <usage> <command> ...
Cause: A global CLI flag was placed after the subcommand name.
Remedy: Place global options before the subcommand: clio-coder --api-key <key> run "..." instead of clio-coder run --api-key <key> "...".
no trace database yet at <path> / error: trace database not found: <path>
Cause: No sessions or runs have executed, or an explicit --db <path> points to a nonexistent file.
Remedy: Execute a command or turn to initialize the SQLite database, or omit --db to use the default state root (~/.local/state/clio-coder/trace.sqlite).
target <id> is not registered
Cause: The designated target ID does not exist in settings.yaml.
Remedy: Run clio-coder targets to view active targets, or register a new target using clio-coder targets add.
worker_final_output_missing
Cause: Worker subprocess exited 0 but emitted no final output before closing.
Remedy: Inspect worker event log with clio-coder trace tail <runId> or inspect receipt with monitor(run_id="<id>", mode="receipt").
vram_capacity_fit_failure
Cause: Target node does not have sufficient GPU VRAM capacity for the model.
Remedy: Select a smaller quantized model variant (e.g. Q4_K_M), reduce context window, or route to an alternate node.
loop_guard_tools_disabled_exhausted
Cause: Loop detector identified repeated unproductive tool calls with identical arguments.
Remedy: Provide clearer intermediate steering instructions to break recursive tool call cycles.
cwd-fallback: no-cwd / missing / not-a-directory
Cause: Recorded session workspace directory has been moved, unmounted, or deleted.
Remedy: Select an existing valid directory when prompted by the CWD fallback interactive dialog.
LM Studio duplicate model load / peer projection
Cause: Sending bare model keys when resident instances exist, or requesting dual-host LM Link projections.
Remedy: Clio resolves model IDs to resident instances (#113). Run clio-coder targets --probe to inspect loaded server instances.
llama.cpp 400 model is already running
Cause: Requesting load for an idle or sleeping model in llama.cpp router.
Remedy: Sleeping models are treated as resident (#127, #134). Verify router slots before requesting eviction.
OAuth token exchange cancelled
Cause: In-flight OAuth login or refresh was cancelled before credential commitment.
Remedy: Re-run clio-coder auth login <target> to restart flow. Uncommitted tokens are discarded cleanly.

Standard Diagnostic Toolchain

Command Diagnostic Purpose When to Use
clio-coder doctor Inspects system dependencies, folder permissions, config schemas, and detected coding peers. First step for any runtime or environment anomaly.
clio-coder doctor --fix Repairs folder permissions (chmod 0o600 credentials), creates missing directories, and updates install metadata. After upgrades or permissions warnings.
clio-coder targets --probe Tests network connectivity, authentication tokens, and model listings for all configured providers. When model calls timeout or return auth errors.
clio-coder trace tail <runId> Streams granular NDJSON event logs and tool execution records from the SQLite trace store. Investigating failed or stuck worker runs.
clio-coder reset --cache Clears stale runtime caches without affecting configuration, credentials, or sessions. Resolving cache corruption or schema drift.

Local Runtime & Inference Server Quirks

LM Studio Instance Resolution (#113)

  • Bare model keys are resolved against resident instances on the target host.
  • Prevents server from loading a second 27B model copy in GPU memory.
  • LM Link peer projections across multiple hosts are flagged and never auto-selected.

llama.cpp Residency & Sleep States (#127, #134)

  • Idle models in router sleeping state are recognized as resident.
  • Eliminates repeated 400 model is already running turn failures.
  • Eviction is refused if the replacement model is not in the catalog.

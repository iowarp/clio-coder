Overview Summary

Every file Clio generates has one home: files explicitly requested by a human land in the repo working tree; unprompted/transient outputs land in the gitignored .clio-coder/ project directory or platform state roots, leaving working trees clean.

The Three Audiences

Human Deliverable

User-requested files meant to be committed. Located at the explicit path the user named in the workspace.

Human Transient

Files a human may want to inspect once. Located under gitignored .clio-coder/artifacts/ or XDG roots.

Agent-to-Agent State

Plumbing between turns, workers, and sessions. Stored in .clio-coder/ or XDG data/state/cache.

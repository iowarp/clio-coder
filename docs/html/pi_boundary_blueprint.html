SDK Ownership Decisions (Pi 0.84.0)

Clio uses Pi SDK libraries for provider protocols, message conversions, and terminal primitives. An action marked Keep represents an explicit architectural product boundary.

Pi Primitive / Export Clio Target File / Area Action Rationale
truncateHead, truncateTail, truncateLine src/tools/truncate.ts Route Pi owns UTF-8-safe truncation. Clio retains 16 KiB default and line-counting helper.
StringEnum src/tools/string-enum.ts Route Replaces TypeBox copy with Pi's compact provider-safe string enum schema.
COMPACTION_SUMMARY_PREFIX, bashExecutionToText src/engine/messages.ts Route Aligns replayed message texts with LLM expectations while keeping Clio ledger entries.
stripTerminalSequences src/domains/session/tree/preview.ts Keep Clio sanitizer strips private-mode CSI escapes from captured tool output.
isRetryableAssistantError src/domains/session/retry.ts Route + Delta Routes generic errors through Pi and preserves Clio's 15s local-model load delay.
retryAssistantCall src/interactive/chat-loop.ts Keep Clio uses interactive turn recovery with visible cancellable countdown.
Provider.auth.oauth src/engine/oauth.ts Route + ALCF Routes built-in OAuth through Pi; preserves custom ALCF Globus PKCE flow.
CredentialStore src/domains/providers/auth/storage.ts Keep Clio's locked YAML storage (0o600) and target-first registry are product invariants.
JsonlSessionRepo / v4 Session src/domains/session/** Keep On-disk ledger v3, active tree graph, and receipts form Clio's durable state spine.
Markdown, renderLatex src/interactive/renderers/** Route Routes terminal rendering, box-drawing Mermaid, and Unicode LaTeX through Pi.

Thin-Wrapper Watchlist

Inspect these files first during SDK updates to avoid reimplementing upstream primitives:

Engine Layer

  • src/engine/apis/index.ts: API provider registration via pi-ai /compat.
  • src/engine/apis/openai-completions.ts: Compatibility flags, sampling, and thinking budgets.
  • src/engine/provider-payload.ts: Retains OpenAI Responses reasoning-summary patch.
  • src/engine/types.ts & ai.ts: Erased Pi types and StringEnum schemas.

Interactive & Session Layer

  • src/domains/session/retry.ts: Wraps isRetryableAssistantError with local model delays.
  • src/interactive/chat-renderer.ts: Replay message phrasing via src/engine/messages.ts.
  • src/domains/config/keybindings.ts: Keybindings mapping over Pi editor actions.

Snapshot Gate (`docs/pi-surface.json`)

Clio maintains a declaration snapshot in docs/pi-surface.json. The scripts/check-hygiene.ts gate enforces:

  • Fails if any imported SDK symbol changes or disappears.
  • Reports newly exported primitives for architectural review.
  • Ensures deliberate decisions for all newly introduced SDK features.

Overview Summary

Clio Coder v0.3.2 enforces strict CLI exit code semantics (0=success, 1=operational failure, 2=usage error, 3=unmeasured harness state) and guarantees linear, non-duplicating NDJSON event streaming over stdout with telemetry separated to stderr.

Process Exit Codes

0

Success

Clean command settlement, --version, --help invocation, or missing trace database notice without an explicit --db flag.

1

Operational Failure

Model execution error, unreachable target, doctor unresolved diagnosis, explicit missing --db, or evaluation rubric failure.

2

Syntax / Usage Error

Unknown subcommand, invalid flag, missing required argument, global flag placed after subcommand, or data mutation SQL query.

3

Unmeasured State

Specific to skills eval: rubric unparseable, judge timeout, or harness infrastructure failure (distinct from negative verdict).

Machine-Readable NDJSON Streaming

When running clio-coder run --json, event frames stream incrementally:

{"type":"session","id":"01912a34...","cwd":"/workspace"}
{"type":"agent_start","agentId":"coder","model":"qwen3.8-27b"}
{"type":"turn_start","turnId":"turn-01"}
{"type":"text_delta","delta":"Analyzing codebase..."}
{"type":"tool_execution_start","tool":"read","callId":"call-01"}
{"type":"tool_execution_end","tool":"read","callId":"call-01","ok":true}
{"type":"turn_end","turnId":"turn-01"}
{"type":"agent_end","usage":{"totalTokens":4200,"costUsd":0.004}}

Flag Positioning & I/O Guarantees

Global Flag Order Invariant

Global flags (--api-key, --no-context-files, -nc) must precede the subcommand. Incorrect positioning emits exit code 2 with guidance on stderr:

error: --api-key is a global option and must come before the subcommand: clio-coder --api-key <key> <command> ...

Standard I/O Separation

  • stdout: Strictly reserved for final deliverables, answers, and NDJSON streams.
  • stderr: Telemetry, notices, permission advisories, and diagnostics.

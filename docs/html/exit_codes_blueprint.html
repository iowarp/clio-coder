Deterministic Process Exit Codes

Clio Coder follows a strict exit code contract across all CLI subcommands:

Exit Code Classification Typical Conditions & Guarantees
0 Success Command executed successfully, --help output delivered to stdout, --version emitted, or empty trace database notice rendered without explicit --db.
1 Operational Failure Model target unreachable, doctor diagnosis with unresolved failures, evaluation rubric failed (fail/error verdict), or explicit --db path missing.
2 Syntax / Usage Error Unknown subcommand, unknown flag, missing required positional arguments, global flag placed after subcommand, or mutating SQL statement passed to trace sql. Output strictly on stderr.
3 Unmeasured / Harness State Specific to evaluation runners (skills eval): rubric could not be evaluated due to timeout, unparseable judge output, or evidence write failure.

The `--help` Standard & Global Options

Strict `--help` Guarantees

  • stdout: Usage guide is printed exclusively to stdout.
  • Exit 0: Always exits with code 0.
  • Zero Side Effects: Runs no network probes, initiates no agent runtimes, and mutates no state files.

Global Flag Positioning

Global flags (--api-key, --no-context-files, -nc) must precede the subcommand name:

# Valid:
clio-coder --api-key <key> run "..."

# Usage Error (Exit 2 on stderr):
clio-coder run --api-key <key> "..."

Machine-Readable Subcommand Formats

Subcommand Invocation Output Structure
clio-coder run --json NDJSON event frames: session, agent_start, turn_start, message_start, message_end, thinking_delta, text_delta, tool_execution_start, tool_execution_end, turn_end, agent_end.
clio-coder run --json-events terminal Receipt-focused stream: emits only session, turn_start, agent_end, turn_end, and notice, plus the synthesized terminal receipt frame (carrying startedAt, endedAt, exitCode, usage). Excludes bulky message bodies (#122).
clio-coder run --json-events full Full event stream with assistant messages projected to strip redundant text bodies, eliminating duplicate wire tokens.
clio-coder trace runs --json JSON array of trace run summary records.
clio-coder trace sql Positional SELECT ... JSON array of query result row objects. Mutating statements exit 2.
clio-coder paths --json JSON object mapping platform directory names to absolute filesystem paths.

Incremental Streaming & Deduplication Invariants (#122, #123)

Delta Deduplication Protocol

Assistant content is streamed incrementally via text_delta and thinking_delta events. To prevent duplicate token delivery, message_end and turn_end project content blocks to lightweight metadata descriptors:

// Projected assistant block in message_end:
{
  "type": "text",
  "streamed": true,
  "textLength": 42
}

Headless Permission Denials

When a mutating tool requires confirmation in headless mode, Clio returns HEADLESS_PERMISSION_DENIED_REASON to the agent as a tool result:

clio-coder run cannot confirm permission requests; rerun interactively to approve this action.

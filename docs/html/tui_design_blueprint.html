Overview Summary

Clio's interactive TUI operates under the core design tenet: color indicates state, boxes outline structure, and brand icons represent identity. Everything that is not state or structure remains visually quiet.

Fullscreen Mode & Screen Architecture

Fullscreen Alternate-Screen Renderer

Opt-in via terminal.tuiMode: "fullscreen" (restart required):

  • Docked composer, follow-up queue, and footer remain locked at the bottom.
  • Transcript and launchpad occupy an independently scrollable upper viewport.
  • PageUp / PageDown scroll one viewport; Home / End jump to bounds.
  • Ctrl+Shift+Up / Ctrl+Shift+Down jump between semantic prompts via OSC 133 prompt markers.
  • terminal.fullscreenScrollbar: hidden, auto, or always.
  • Manual scrolling suspends follow-end until the operator returns to the bottom.

Prompt Navigation History

Process-local navigation history via Ctrl+P and Ctrl+N:

  • Accepted chat turns, slash commands, steering inputs, follow-ups, and interrupts are recorded.
  • Consecutive duplicates are collapsed.
  • Rejected or malformed inputs remain editable in the composer without polluting history.
  • Navigating forward past the newest entry cleanly restores the unfinished draft prompt.

Tool Ledgers, Diffs, and Approval Facts

Stable Tool Lifecycle Rows

Every tool call owns one stable transcript row from start to settlement:

  • forming call → ready → running → settled.
  • Running calls display live output and stream partial results in place.
  • Parked calls display transient approval facts: action class, asking safety axis, and target.
  • Settled calls display exit code, byte/line counts, duration, and full output path.

Word-Level Diffs & Diagram Rendering

  • edit / write: Render numbered diffs with word-level changes highlighted in success green and error red.
  • Mermaid Diagrams: Fenced mermaid blocks render as Unicode flowcharts, state diagrams, and class diagrams when they fit width-wise.
  • Unicode LaTeX: Math expressions like $x^2$ render as Unicode (x²) without external image dependencies.

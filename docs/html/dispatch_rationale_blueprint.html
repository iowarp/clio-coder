Overview Summary

Why src/domains/dispatch/ maintains cohesive invariants across routing, admission, retries, write-boundaries, and receipts rather than splitting artificially along responsibility labels.

Constraints Required for Any Future Split

  1. One hashed plan: Deterministic hashed DAG with wave computation and authority grants.
  2. Serialized admission: Single cross-process lock protecting lease acquisition, drain, and reservation transfer.
  3. Attempt identity: Assignment ID distinct from terminal run ID; recovery role preserved.
  4. Fail-closed defaults: Missing candidates, manual pins, or unverified boundaries refuse execution.
  5. Receipt sealing authority: Orchestrator validation decides conformance.

Size Does Not Argue for a Split

src/domains/dispatch/ contains 65 TypeScript files with a single cohesive purpose. Proposing a multi-way split by responsibility labels is flawed because core invariants cross those labels rather than partitioning neatly between them.

Architectural Invariant Crosses Boundary Seams Source Evidence

Five Preservation Pillars for Future Architecture

1. One Hashed Plan DAG

compileExecutionPlan produces one deterministic hashed DAG including unrolled loops, wave computation, and authority grants.

2. Single Cross-Process Lock

Lease acquisition, retry rebinding, heartbeats, and cluster drain run in one critical section under dispatch-admission.json lock.

3. Attempt & Assignment Identity

Logical assignment ID and physical run ID are strictly distinct; recovery role derivation is shared across the entire fleet.

4. Fail-Closed Defaults

No-candidate states, manual pins, failover: none, and unverifiable write boundaries fail closed unconditionally.

5. Orchestrator-Side Receipt Sealing

The orchestrator's verification, not the worker's self-report, authoritatively decides conformance and cryptographically seals the receipt.

Direct Subpath Import Rationale

Direct vs Barrel Imports

  • 110 Direct Subpath Imports vs 29 Barrel Imports across src/domains/**.
  • Boundary checkers enforce dependency direction (who depends on whom), not artificial import form.
  • Avoids polluting public barrel interfaces with internal types needed by specific subpath callers.

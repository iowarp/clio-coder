Supported ACP Methods

The native ACP server (clio-coder acp) exposes JSON-RPC 2.0 methods over stdio. Diagnostics route exclusively to stderr.

Method Direction Description
initialize Client → Server Negotiates protocol version (1), agent capabilities, and implementation metadata. Exactly once.
session/new Client → Server Binds the single hosted session, snapshots autonomy, and records initial orchestrator routing.
session/load Client → Server Resumes a closed session from the launch workspace and replays bounded original turn updates.
session/prompt Client → Server Submits a user prompt to the execution loop; streams updates and tool progress.
session/cancel Client → Server Cancels in-flight execution, active tool operations, and pending permission requests.
clio-coder/session/list Client → Server Lists bounded session summaries from the canonical workspace. Legal during turns.
clio-coder/session/autonomy Client → Server Reads or overrides session autonomy level (read-only, suggest, auto-edit, full-auto).
clio-coder/settings/get_safe Client → Server Reads closed credential-free settings projection (orchestrator.*, autonomy).
clio-coder/settings/patch_safe Client → Server Atomically validates and persists a flat patch over the safe settings subset.
session/request_permission Server → Client Requests client-side approval for a gated mutating action.

Structured Error Envelope & Closed Taxonomy

Wire Format & Redaction

Clio errors use code -32000. Wire messages are short (≤256 chars), single-line, and strictly redact file paths, stacks, URLs, and secrets:

{
  "code": -32000,
  "message": "the prompt turn failed",
  "data": {
    "_meta": {
      "clio-coder/error": {
        "version": 1,
        "code": "turn_failed",
        "supported": [1]
      }
    }
  }
}

Closed `data.code` Values

  • not_initialized / already_initialized
  • protocol_version_unsupported (code -32602)
  • invalid_params (code -32602, reason details)
  • session_cwd_mismatch / session_limit
  • session_unknown / session_open
  • prompt_active / prompt_not_admitted
  • permission_expired (audited as expired, not denied)
  • turn_failed / internal_error

Security & Workspace Invariants

Invariant Enforcement Mechanism
One Session per Process Exactly one session/new or session/load succeeds per process. Secondary attempts fail with session_limit.
Workspace Pinning The launch --cwd is resolved with fs.realpath at boot. The process never calls chdir, and relative paths in session/new are rejected.
Permission Timeout Ceiling --permission-timeout MS sets fail-safe ceiling. Expired requests abort execution safely and audit as expired, never as human denials.
Safe Settings Projection Only 4 editable fields (orchestrator.target, model, thinkingLevel, autonomy) cross the wire. Secrets and URLs are never exposed.
Replay Caps Session load replays retain newest 64 user turns, at most 8,192 tool starts, and ≤4 MiB serialized frames.

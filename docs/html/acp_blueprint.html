Overview Summary

Clio Coder implements ACP v1 (schema 0.4.5) over JSON-RPC 2.0 stdio transport via clio-coder acp, allowing IDEs like Zed or custom external coordinators to drive Clio sessions safely with full permission mediation and bounded error envelopes.

ACP Methods Taxonomy

initialize Client → Server
session/new Client → Server
session/load Client → Server
session/prompt Client → Server
session/cancel Client → Server
session/request_permission Server → Client

Safe Error Envelope Contract

Every error returned over JSON-RPC uses code -32000 and places machine-readable codes in data._meta["clio-coder/error"]. Secrets, file paths, and raw stack traces are stripped to protect privacy.

{"code":-32000,"message":"the prompt turn failed",
 "data":{"_meta":{"clio-coder/error":{"version":1,"code":"turn_failed","supported":[1]}}}}

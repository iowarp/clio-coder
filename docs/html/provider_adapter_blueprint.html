Adapter Capability Requirements

Clio's runtime uses standard features mapped as follows:

Chat Completion (REQUIRED) The model must process system instructions and a replayed array of assistant/user/tool messages.
Function Calling / Tools (HIGHLY RECOMMENDED) Enables Clio to issue file search, read, write, and bash commands. If disabled, Clio acts in a conversational-only posture.
Structured JSON Outputs (RECOMMENDED) Used for structured change manifests (`clio-coder evolve`) and local evaluation reports.
Fill-in-the-Middle FIM (OPTIONAL) Enables surgical code edits when exact line matching fails.

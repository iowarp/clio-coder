Trace Store Blueprint

Interactive reference and query validator simulator for the SQLite trace mirror (v0.3.4)

v0.3.4 Trace Mirror

Clio's trace database is a rebuildable, queryable SQLite mirror located at <stateDir>/trace.sqlite. Authoritative state remains in receipts, ledgers, and gate artifacts. Removing trace.sqlite causes no data loss. Writers enforce WAL journal mode and busy_timeout=5000; readers open in read-only mode.

clio-coder trace Subcommands

The CLI exposes six dedicated subcommands for operational tracing and diagnostics:

clio-coder trace runs [--db PATH] [--limit N] [--json]

Queries and formats recent execution runs up to limit N (1 to 500, default 50). Displays run status, start timestamp, total tokens, USD cost, and run ID.

clio-coder trace phases <runId> [--db PATH]

Lists execution phases for a specified run. Displays phase status, attempt index, owner, token count, USD cost, and phase name.

clio-coder trace tail <runId> [--follow] [--db PATH]

Streams append-ordered trace events by SQLite rowid. When --follow is enabled, polls every 500 ms until two consecutive idle polls observe a completed run status.

clio-coder trace procs <runId> [--db PATH]

Displays process records (orchestrator and worker) registered for a run. Shows process state (live or ended), PID, kind, name, and command line.

clio-coder trace sql <SELECT query> [--db PATH]

Executes a single read-only SELECT or WITH query against the trace store. Rejects semicolons and data modification statements (INSERT, UPDATE, DELETE, etc.).

clio-coder trace ui [--db PATH] [--port N]

Launches the web-based trace viewer server on the specified port. Requires source checkout with apps/trace-viewer/server.mjs.

Database Schema

runs

Terminal run records, statuses, models, targets, node, timing, total tokens, total USD cost. Interactive session turns are recorded here too, under assignment_id "session".

phases

Sequence phases, attempt index, retries, worker owner, itemized token and dollar spend, context occupancy.

events

Append-ordered events by rowid. Tool calls are spans with ended_at; point events have null ended_at.

envelopes

Agent output envelopes, valid flags, attempt indices, and output types.

gate_results

Typed reviewer/judge verdicts, passed status, and itemized checks JSON array.

agent_sessions

Mirrored worker/model/session context occupancy records.

processes

Registered worker processes, PIDs, redacted command string, and SHA-256 command digest.

meta

Schema version metadata table (enforces schema_version = 1).

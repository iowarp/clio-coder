CLI Quick Reference

Launch the visual docs server from your local Clio checkout workspace environment:

# Start local http server and open landing page
clio-coder docs

# Jump directly to safety specs page
clio-coder docs safety

# Print only the bound port url without launching a browser
clio-coder docs --no-open

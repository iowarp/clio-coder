Overview Summary

Clio Coder enforces a strict separation between monotonic clocks for durations and wall clocks for anchored instants, stores all timestamps as UTC ISO-8601 strings, and converts to local operator time only at user interface render boundaries.

Monotonic vs Wall Clocks

Monotonic Clocks (performance.now / hrtime)

Used for all duration measurements, time-to-first-token (TTFT), execution budgets, watchdogs, and retry intervals. Unaffected by NTP skew or DST shifts.

Wall Clocks (Date.now / new Date)

Reserved strictly for anchoring human-visible instants (startedAt, endedAt, createdAt). Never used to calculate elapsed spans directly.

Combined Anchor & Span Pattern

const startedAtMs = Date.now();                      // wall anchor
const clock = process.hrtime.bigint();               // monotonic span
const startedAt = new Date(startedAtMs).toISOString();

// ... execution happens ...

const durationMs = Number((process.hrtime.bigint() - clock) / 1_000_000n);
const endedAt = new Date(startedAtMs + durationMs).toISOString();

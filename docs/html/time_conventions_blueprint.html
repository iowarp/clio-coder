Which Clock for What Purpose

Monotonic Clocks for Spans & Durations

All durations, latencies, TTFT, timeouts, watchdogs, and retry backoffs MUST use performance.now() or process.hrtime.bigint():

  • Immune to NTP stepping, system sleep/wake, and DST clock shifts.
  • Answers: "How long did this take?" or "How long until timeout?".

Wall Clocks for Anchored Instants

Date.now() or new Date().toISOString() are reserved exclusively for anchor timestamps that humans or external systems inspect:

  • Includes startedAt, endedAt, createdAt, expiresAt.
  • NEVER used for calculating elapsed durations or intervals.

Combined Anchor and Span Pattern

When recording an operation with both an anchor and an exact duration (e.g. src/domains/dispatch/code-step.ts):

const startedAtMs = Date.now();                      // wall anchor, for the record
const clock = process.hrtime.bigint();               // monotonic span
const startedAt = new Date(startedAtMs).toISOString();

// ... execution runs ...

const durationMs = Number((process.hrtime.bigint() - clock) / 1_000_000n);
const endedAt = new Date(startedAtMs + durationMs).toISOString();

// Guarantees: endedAt - startedAt === durationMs, unaffected by NTP shifts

Storage, Transport, and Comparisons in UTC

UTC Invariants

  • Storage: All timestamps in JSON/JSONL are canonical ISO-8601 UTC strings.
  • Transport: Stored and sent across stdio/NDJSON as UTC.
  • Comparisons: Time comparisons are performed on UTC epoch milliseconds.

Render-Boundary Conversion

Conversion to the operator's local timezone occurs strictly at the final UI render call site:

  • The canonical UTC instant remains accessible in detail views.

Standardized Formatter Functions (`src/interactive/format-time.ts`)

Function Output Format Locale & Frame Purpose
clockLocal(instant) HH:MM:SS Operator local timezone (en-GB, 24h) Renders time-of-day for logs, tree selectors, and message pickers.
dateLocal(instant) YYYY-MM-DD Operator local timezone (en-CA) Renders calendar dates for session pickers, welcome dashboards, and export files.
relative(instant, now) "3m ago" Operator local timezone Renders relative recency ladders with automatic fallback to calendar dates.

Sequence Ordering & Cross-Host Boundaries

Sequence Numbers Over Timestamps

Under concurrent execution, components like the agent ledger and execution scheduler rely on monotonic sequence numbers rather than timestamps for total ordering.

Cross-Host Boundaries

Timestamps produced on one host are never compared directly against clocks on another host. Events are receive-stamped locally on arrival.

Test Determinism & Steppable Harness

In test suites (tests/harness/clock.ts):

  • Every module that reads a clock accepts an injectable clock interface.
  • Test harnesses advance time deterministically via steppable clocks, eliminating flakes and real-time passage delays.
  • Receipt integrity digests seal normalized timestamps before sealing; timestamps are never rewritten after receipt creation.

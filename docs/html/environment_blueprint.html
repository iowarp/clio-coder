Overview Summary

Environment variables allow operator-scoped and process-scoped overrides (such as CI or one-off tests). The settings YAML file remains the primary home for durable configuration, but env vars override settings values on runtime startup.

Variables Matrix

Filter or search process environment variables:

Variable Default Controls / Scope
CLIO_CODER_TURN_TOOL_CALL_BUDGET 60 Orchestrator per-turn soft tool-call budget; hard ceiling sits 15 above.
CLIO_CODER_WORKER_TOOL_CALL_CAP 150 Lifetime tool-call cap per dispatched worker process run.
CLIO_CODER_INTERNAL_DISPATCH_TIMEOUT_MS 900000 Internal dispatch execution timeout in milliseconds (15 minutes).
CLIO_CODER_MAX_DISPATCH_RUNS 1000 Dispatch run-ledger retention cap. The older CLIO_CODER_MAX_RUNS spelling still reads when this one is unset.
CLIO_CODER_READ_MAX_BYTES 51200 Per-call byte cap for the file read tool (min 1024).
CLIO_CODER_OBSERVATION_TURN_BUDGET_BYTES 196608 Shared per-turn byte pool across observation tools.
CLIO_CODER_RIGOR repo-derived Finish-contract evidence validation bar (normal or high).
CLIO_CODER_RESIDENCY managed Control local model residency managers (managed/observe/off).
CLIO_CODER_TRUST_PROJECT_SKILLS off Enable project-local skills execution (1/0).
CLIO_CODER_ALLOW_EXTERNAL_FULL_ACCESS off Let full-auto pass to external runtimes.
CLIO_CODER_HOME unset Override installation root path. Sets config, state, and cache relative to it.
CLIO_CODER_CONFIG_DIR Platform XDG Settings directory path override.
CLIO_CODER_DATA_DIR Platform XDG Data directory path override.
CLIO_CODER_STATE_DIR Platform XDG State and session directory path override.
CLIO_CODER_CACHE_DIR Platform XDG Marketplace/models caching path override.
CLIO_CODER_BUS_TRACE off Trace event-bus events to stderr.
CLIO_CODER_TIMING off Print boot timing reports.
CLIO_CODER_INTERACTIVE off Flag indicating interactive TUI mode. Cleaned from children.
CLIO_CODER_RUN_OVERRIDES unset JSON envelope for process option bindings.
CLIO_CODER_WORKER_FAUX unset Fake LLM responses mapping framework for test assertions.

Worker Exit Codes Specs

Parent checks exit codes when child process terminates:

Exit Code Symbolic Name Triggering Condition
0 WORKER_EXIT_SUCCESS Run finished successfully with finish-contract evidence.
1 WORKER_EXIT_GENERIC_ERROR Unhandled exception or parsing crash during chat loop.
3 WORKER_EXIT_PERMISSION_REQUIRED A suggested tool required approval under strict non-interactive policy.
4 WORKER_EXIT_SIGTERM Watchdog timed out or operator aborted execution stream.

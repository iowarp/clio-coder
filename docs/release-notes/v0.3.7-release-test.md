## Release verdict

Ship 0.3.7. Every defect I filed is closed, and each fix was re-verified in a fresh session against the rebuilt artifact rather than a rerun of the one that failed. The last one landed in round 5: `/share <synthesis runId>` now renders the bounded council block — both final members' answers under their roster labels plus the `[synthesis vote] verdict … · tally` line — and the main agent acted on it, spot-checking the cited files and returning a decision, where in round 4 it had correctly reported that the raw payload gave it nothing to work with.

The substance of the release is verified against sealed evidence rather than screen output. Typed dispatch intent and host-run verification seal correctly at receipt integrity v19, with per-check argv, cwd, exit code, bounded output tail and artifact path, a normalized `intent` carrying the `gate:` shorthand folded into a verification entry, and `host_verification_rejected` turning a red check into a failed run that suppresses retry. Worktree-per-task runs on `clio/task/<runId>`, merges when clean, and fails closed as `worktree_merge_conflict` with the branch and worktree preserved when main moves under it. The checkout writer lease refuses a live sibling by pid. `writers: 1` serialized two writers in declared order with no overlap in their receipt timestamps. The fleet authoring CLI is solid end to end, including `--resume` and its per-step plan-hash diff. Contract v5 works in both new shapes: `kind: gate` fires `gate_not_discriminating` on a green baseline and seals `fleetGate`, and `kind: plan` splices tasks that carry lineage back to the plan run. `/fleet run` previews waves, routes, argv and the budget ceiling, dispatches through the shared path on Enter, writes a durable record the CLI can resume, and cancels cleanly on Esc. The resource library writes nothing without `--yes` and pins what it writes; the Skills Hub kind tabs install behind a confirmation; the watchdog fires exactly once on an editing turn and not at all otherwise; `/btw` stays out of the session JSONL while showing up in `/cost` and the durable out-of-turn store that feeds `usage report`.

Two cosmetic follow-ups are worth a line in 0.3.8, neither a reason to hold: a gate step that also declares `writes` is refused with `/steps/0: must have required properties scope`, which names a property the author never touched (D4), and an out-of-range watchdog cadence is rejected silently with no message (D8). Across five rounds: 94 pass, 15 fail (all 13 distinct defects fixed), 2 blocked, 6 not run. Nothing is outstanding.

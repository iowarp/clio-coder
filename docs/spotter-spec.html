Zero Latency & PTY Isolation

Standard screen recording consumes high CPU/GPU and drops frames. Spotter taps directly into Clio's stream pacer and raw PTY output with microseconds latency and no visual artifacts.

Cryptographic Evidence Binding

Every .cast stream is hashed (SHA-256) and permanently sealed into Clio's RunReceipt v20, guaranteeing deterministic auditability and scientific reproducibility.

Stream to Anywhere

Broadcast live terminal feeds over local ephemeral HTTP servers, remote ALIS relays (ALCF/NERSC cluster nodes), or embedded WebSocket channels in Clio Workbench.

Spotter CLI Commands

1. Live Interactive Streaming CLI
clio-coder spotter live --local 0.0.0.0:8448

Launches Clio interactive chat while streaming live to local web player for peer review.

2. Remote HPC Cluster Relay HPC / SLURM
clio-coder fleet run --spotter-relay wss://spotter.iowarp.ai

Streams headless Slurm/MPI compute node jobs across isolated networks to team dashboard.

3. Replay with Marker Navigation AUDIT
clio-coder spotter play run-2135i51e5gys --pause-on-markers

Replays a recorded worker run inside terminal, stepping directly through tool/bash decisions.

4. Export to High-Gloss Media EXPORT
clio-coder spotter export run-2135i51e5gys -o pr-demo.gif

Renders asciicast recording into lightweight GIF/MP4 via bundled Rust agg engine.
